# kicktipp-bot-research

Wird automatisch von einer geplanten Claude-Cloud-Routine befuellt.
Enthaelt Recherche-Ergebnisse (Verletzungen/News-basierte Tipp-Einschaetzungen)
zu anstehenden Bundesliga-Spielen fuer den Kicktipp-Auto-Tipper.

Datei: research.json
Format: { "<match_id>": {"home_goals": int, "away_goals": int, "reasoning": "...", "generated_at": "ISO-timestamp"} }
